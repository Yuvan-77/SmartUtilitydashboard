Project Title

Smart Utility Dashboard – A Multi-Utility Web Application

Project Description

The Smart Utility Dashboard is a web-based application developed using HTML, CSS, and JavaScript. It combines multiple everyday utility tools into a single platform, allowing users to perform common tasks efficiently without switching between different websites or applications.

The application provides six essential utilities:

Weather Dashboard
Scientific Calculator
Unit Converter
Currency Converter
Stopwatch & Timer
Age Calculator

This project demonstrates front-end web development concepts, JavaScript programming, DOM manipulation, and API integration.
